KAVACH AI
Crime Intelligence Desktop Application

IMPORTANT
=========

This release uses synthetic demonstration data.

It is not an official police information system.
It must not be used for real enforcement, prosecution,
individual risk assessment, or automatic decision-making.

FIRST START
===========

1. Start Kavach AI.
2. Create the first administrator account.
3. Use a password containing at least 12 characters.
4. Store the administrator credentials securely.
5. Create lower-privilege operator accounts for normal use.

LOCAL STORAGE
=============

Operator accounts, sessions, and audit logs are stored under
the current Windows user's Kavach AI application-data folder.

The packaged application includes its own synthetic dataset
and embedded local API. No separate Node.js or API server
installation is required.

REPORTS
=======

Reports generated by this release are investigative-support
documents using synthetic demonstration data. They are not
official police records or legal determinations.
